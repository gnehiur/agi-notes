# AGI Notes

通往新范式 AGI 的公开研究仓库。

## 核心判断

人脑以约 20 瓦的功耗实现了通用智能，当前最强的模型能耗高出若干个数量级。这个差距几乎必然意味着当前范式在某种根本意义上是错的，而不只是"还没优化好"。人脑是存在性证明，也是蓝图的主要来源——但**人类是灵感，不是最优解**：对人脑的每个机制都要追问它是智能的必要结构，还是生物约束的产物。

我的架构假设围绕几个支柱展开：融入模型内部的短期权重（Fast Weights 一族）、增量输入的有状态交互、赫布学习替代反向传播、类睡眠的离线固化、权限分层的目标系统。完整论证见 [vision.md](vision.md)。
