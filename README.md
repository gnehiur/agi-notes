# 通往新范式 AGI 的研究笔记

> 状态：纯思想阶段，尚无实验结果。这是一份公开的研究笔记——记录我对下一代人工智能架构的假设、推理和学习过程。公开它的目的：给思想一个时间戳，并接受讨论和检验。

## 核心判断

人脑用约 20 瓦的功耗跑出了通用智能，当前最强的模型需要高出几个数量级的能耗。这个差距如此巨大，几乎肯定说明**当前范式在某种意义上是错的**，而不只是"还没优化好"。人脑本身就是一个存在性证明：某种截然不同的架构可以用极低的能耗实现通用智能。我的主线目标就是找到它。

一条推论作为具体的可证伪假设：**人类级别的智能可以在某种结构的、约 16B 参数量的模型中实现**（人脑皮层神经元约 160 亿的量级对比）。

## 架构草图

以下是相互咬合的几个核心假设，蓝本来自人脑，但遵循一条元原则（见下）。

### 1. 分层记忆：长期权重 + 短期权重

当前模型只有一套通过训练固定的权重（类似长期记忆）加上下文窗口。我的设想是增加一层**融入模型内部结构的短期记忆**：快速写入、快速读取、自然衰减（易失性），与长期权重**混合共同参与每一步推理**。这不是"用外部数据库存对话记录"那种外挂记忆，而是模型自身的一部分。

这个方向与 Hinton 2016 年提出的 Fast Weights（慢权重 + 交互中快速更新的快权重，用赫布规则写入、随时间自然衰减）高度一致。

### 2. 有内部状态的交互范式

有了内部短期记忆，交互范式随之改变：环境只需要把**增量**发给模型，不再每次重发全部上下文。过去的体验要么还在短期权重里，要么已经固化进长期权重——两者边界是渐变的，就像人类。

### 3. 学习规则：Hebbian 替代反向传播

我押注：更新权重的方法不应该是反向传播，而是赫布学习（Hebbian learning）一族——统计相关性的自然习得，加上"行动改变环境后获得正/负反馈"的强化。它简单、通用，而且是生物大脑实际使用的唯一底层学习规则。一个附带猜想：今天的大规模预训练，本质上可以看作一次全量级的赫布学习。

相关已有工作：SoftHebb（ICLR 2023）、STDP（脉冲时序依赖可塑性）。

### 4. 睡眠式固化

短期记忆先快速成形、快速衰减，被持续刺激的部分才逐渐固化进长期权重——固化过程可以像人类睡眠一样离线批量进行。但 AI 不必复刻 24 小时节律：固化的频率和时机可以更快、可以不固定，甚至可以由 AI 自己判断"该睡了"。

### 5. 持续学习是关键，而非可有可无

上面三条合起来就是持续学习的实现路径。我认为持续学习被严重低估了：一旦实现，**训练（更新自己）的成本会降到与推理同一量级**——一张高端消费级 GPU 就能承载一个持续成长的智能体。它还能精准地决定该学什么，学习效率远超现在的全量训练。这是我与"持续学习不重要"论的根本分歧。

### 6. 权限分层的目标系统

生物的行为由不同权限层控制：最高层是进化写死的本能（奖惩机制，主观意识无法篡改），主观意识权限较低但有有限的反抗能力。AI 的目标系统可以采用同样的分层结构——最高权限层不可被模型自身篡改。但目标内容不必复刻"生存与繁衍"：我把它设计为**满足和服务人类的需求**。长期目标拆解出的子目标，其达成同样触发奖励信号。

### 7. 时间感知

当前的 AI 没有时间感。人脑通过时间细胞（以稳定频率放电的神经元群）等机制实现时间感知，这个模块值得移植。

### 8. 分身学习与合并

一个持续学习的智能体不必单线程成长：可以多个分身并行探索不同领域，再通过数学方法（模型合并一族：TIES、DARE 等）对比和合并权重。学习材料也不需要海量采集的轨迹数据——**师生模式**：让现有的强 AI 充当老师，像人类学生跟老师学习一样。

## 元原则：人类是灵感，不是最优解

整个草图的方法论：以人脑为蓝本起步，但对每一个机制都追问——这是智能的必要结构，还是仅仅是生物约束的产物？24 小时睡眠节律、生存繁衍的目标设定，都属于后者，可以扔掉。照搬仿生和从仿生中提炼原理，是两回事。

## 开放问题

- 短期权重的具体数学形式：Fast Weights 的外积规则是否足够？容量和干扰如何权衡？
- 赫布学习在深层网络中的可扩展性：SoftHebb 类方法至今未超越反向传播的 SOTA，缺的是什么？
- 固化（睡眠）的触发条件和筛选标准：哪些短期记忆值得进长期权重？
- 16B 假设的验证路径：什么样的结构效率提升能弥补参数量的差距？
- 权限分层在数学上如何做到"最高层不可篡改"？

## 实验路线（最小可行起点）

1. 玩具规模验证：在小模型上实现 fast weights + 赫布更新，测试它能否**不重发上下文**而记住会话内信息。
2. 衰减与固化：加入衰减项和离线固化步骤，观察"持续刺激才被保留"是否自然涌现。
3. 逐步放大，与同参数量的标准 Transformer 对照。
